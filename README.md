# 🎨 AnimeOn Studio

> Расширение для Chrome и Firefox, которое даёт полную кастомизацию сайта **animeon.cc**: темы, обои, шрифты, улучшения плеера Kodik, приватность и многое другое.

🌐 **Сайт проекта:** https://animeonstudio.codeberg.page/
🦊 **Firefox Add-ons:** https://addons.mozilla.org/ru/firefox/addon/animeon-studio/
📦 **Релизы:** https://github.com/Doxinger/AnimeonStudio/releases

## ✨ Основные возможности

- **🎨 Внешний вид:** собственная палитра цветов, пользовательские обои, плавная смена тем.
- **🔠 Типографика:** поддержка Google Fonts, эффект стеклянной шапки (glassmorphism).
- **📺 Плеер Kodik:** театральный режим, подсветка экрана (bias lighting), автопереход к следующей серии.
- **🕶 Пипетка:** скрывайте любые блоки сайта одним кликом.
- **🔒 Приватность:** мягкая и жёсткая блокировка трекеров, автоматическое удаление UTM-меток.
- **💬 Социальные функции:** кастомизация чата, косметика профиля (бейджи, титулы, витрина).
- **🔄 Синхронизация:** перенос настроек между устройствами.

## 📦 Установка

### Firefox / LibreWolf
1. Основной способ — установка из магазина [Firefox Add-ons](https://addons.mozilla.org/ru/firefox/addon/animeon-studio/): дополнение проходит рецензию, обновления устанавливаются автоматически.
2. Альтернатива: скачайте `animeon-studio-v1.1.1-firefox.xpi` (или `.zip`) со [страницы релизов](https://github.com/Doxinger/AnimeonStudio/releases) и распакуйте архив.
3. Откройте `about:debugging#/runtime/this-firefox` и нажмите «Загрузить временное аддон».
4. Выберите файл `manifest.json` из распакованной папки (или из `dist-firefox/` при сборке из исходников). Временный аддон живёт до перезапуска браузера.

### Chrome / Edge / Chromium-based
1. Скачайте `animeon-studio-v1.1.1-chromium.zip` со [страницы релизов](https://github.com/Doxinger/AnimeonStudio/releases) и распакуйте его в удобную папку.
2. Откройте страницу расширений: `chrome://extensions` в Chrome, `edge://extensions` в Edge, `opera://extensions` в Opera.
3. Включите «Режим разработчика».
4. Нажмите «Загрузить распакованное расширение» и выберите распакованную папку (внутри должен лежать `manifest.json`). При сборке из исходников это папка `dist/`.

## 🛠 Сборка из исходников

### Требования
- Node.js 18+
- Python 3 (для упаковки релизов)

### Команды

    # Установка зависимостей (не обязательна: без них сборка пропускает линтер и тесты)
    npm install

    # Линтинг, сборка бандлов (Chromium + Gecko) и запуск тестов
    node tools/build.mjs

> Скрипт `build.mjs` автоматически линтит код, собирает артефакты в `dist/` и `dist-firefox/` из `manifest.template.json`, а также прогоняет smoke- и unit-тесты.

### Упаковка для публикации

    python3 tools/package.py

Скрипт считывает версию из собранного `manifest.json` в `dist/`, упаковывает содержимое собранных директорий в `.zip` (Chrome) и `.xpi` (Firefox/AMO).

## ⌨️ Горячие клавиши

Команды браузера (переназначаются в `chrome://extensions/shortcuts` или в настройках дополнений Firefox):

| Комбинация      | Действие                        |
|-----------------|---------------------------------|
| `Alt+Shift+O`   | Открыть панель расширения       |
| `Alt+Shift+X`   | Включить / выключить расширение |

Клавиши на страницах сайта:

| Комбинация       | Действие                                |
|------------------|-----------------------------------------|
| `Alt+Shift+P`    | Пипетка элементов                       |
| `Alt+Shift+T`    | Театральный режим плеера                |
| `Alt+Shift+C`    | Киносвет                                |
| `Alt+Shift+M`    | Плеер на весь экран                     |
| `Alt+Shift+E`    | Включить / выключить расширение         |
| `Alt+Shift+R`    | Перезагрузить страницу и пересобрать стили |
| `Alt+Shift+Home` | В начало страницы                       |
| `Alt+Shift+H`    | Скрыть шапку                            |
| `Alt+Shift+K`    | Шпаргалка клавиш                        |
